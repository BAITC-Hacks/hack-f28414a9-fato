# 🎙️ AutoProtocol AI — Система автопротоколирования совещаний

## Краткое описание

Автоматизированный сервис для протоколирования совещаний АО «Самрук-Қазына Өңдеу».

Решение принимает аудиозаписи, формирует краткое саммари и извлекает реестр поручений со сроками и ответственными, исключая потерю задач.

## Реализованный функционал

- 📥 Загрузка и воспроизведение аудиозаписей (.mp3, .wav)
- 🗣️ Поддержка русского, казахского и смешанного языков
- 📋 Автоматическая генерация саммари
- 📌 Извлечение поручений (Суть, Ответственный, Срок) с возможностью редактирования
- 📄 Выгрузка протокола в .DOCX
- 🔒 Готовность к развертыванию в On-premise контуре
